# Heart Disease Prediction

Proyek ini merupakan praktikum **Machine Learning**
untuk melakukan analisis dan klasifikasi penyakit jantung
menggunakan dataset `Heart_Disease_Prediction_Dataset.csv`
yang terdiri dari 918 data dan 12 atribut. Proses praktikum
meliputi eksplorasi data (*Exploratory Data Analysis* atau EDA),
prapemrosesan data seperti pemeriksaan nilai kosong dan
duplikasi, penanganan outlier, serta encoding fitur kategorikal.
Selanjutnya, dilakukan pembangunan dan perbandingan tiga algoritma
klasifikasi, yaitu **Logistic Regression, Support Vector Classifier (SVC),
dan Decision Tree**, menggunakan pembagian data latih dan data uji
dengan rasio 80:20. Berdasarkan hasil evaluasi, Logistic Regression
memperoleh akurasi sebesar 86% pada data latih dan 85% pada data uji.
Proyek ini bertujuan untuk memahami tahapan dasar penerapan
Machine Learning dalam analisis data kesehatan dan memprediksi
status penyakit jantung berdasarkan atribut yang tersedia.
